Privacy summary Flintfold Packing Grid is a browser-based packing calculator. Dimensions and layout settings entered into the extension are used to calculate fit counts, orientation comparisons, waste estimates, previews, and exportable summaries. The extension is not designed to use those values for advertising profiles, cross-site tracking, or unrelated analysis of browsing activity.

1. Overview

Flintfold Packing Grid helps users evaluate how rectangular items may fit within a defined surface. The extension accepts basic dimensional inputs, evaluates normal and rotated orientations, calculates approximate fit counts and unused area, presents a compact visual preview, and can produce a CSV summary for reference or planning. This policy applies to information handled through those extension functions.

The extension is designed around a narrow utility purpose and data minimization. Its calculation workflow does not require a personal account, a persistent user profile, access to unrelated websites, or a history of the user's browsing behavior. Information is handled only to the extent necessary to provide the packing comparison and user-requested output.

2. Extension purpose

The specific purpose of Flintfold Packing Grid is to compare two packing orientations for a rectangular item within a rectangular surface. Users can enter surface width and height, an outer margin, item width and height, and spacing between items. The extension uses those values to estimate how many items fit under each orientation and to show which arrangement uses the available area more efficiently.

The interface may display derived information such as the best fit count, number of rows and columns, estimated waste percentage, orientation comparison, and a visual grid preview. These results are mathematical outputs based on the values supplied by the user. They are not intended to identify an individual, infer personal interests, or measure activity outside the extension.

3. Calculation inputs and derived results

Inputs can include numerical values describing the available surface and the item to be packed, including width, height, margin, and gap. These fields are operational values used by the packing formula. Flintfold Packing Grid does not need names, email addresses, passwords, financial details, contacts, precise location, or private communications in order to perform its normal calculations.

From those inputs, the extension may derive quantities such as row count, column count, total pieces that fit, occupied area, estimated unused or waste area, and a recommendation between normal and rotated placement. Derived values remain part of the same calculation task and are used to present the comparison requested by the user.

Numerical dimensions may still represent confidential operational information in some workplaces. Users should enter only the measurements needed for the planning task and should apply their own organization's data-handling rules when appropriate.

4. Information we collect

Flintfold Packing Grid is not designed as a user-data collection service. Its core functionality does not require registration, sign-in, a cloud profile, or submission of personal identity information. The extension is intended to operate as a focused calculator rather than as a service that builds a history of individual users.

Values entered into the packing form and the results produced from them are not intended to be used for targeted advertising, sale of personal data, audience profiling, cross-site tracking, or marketing segmentation. The extension also does not need to inspect search history, browsing history, content from unrelated tabs, private messages, passwords, or form data from unrelated websites in order to perform its published packing functions.

5. Processing of packing calculations

Packing calculations are designed to occur within the extension interface. When a user changes dimensions or requests a calculation, the extension applies its packing logic to the supplied values and updates the displayed comparison. This approach keeps the calculation tied to the immediate user action instead of requiring a remote profiling service or a server-side user account.

The calculation process may temporarily hold the active values and derived results in the extension page while the interface is open so that the user can adjust measurements and compare alternatives without repeatedly re-entering information. Such working state exists to support the current calculation experience, not to create a behavioral record of the user's browsing activity.

6. Visual layout preview

Flintfold Packing Grid can render a simplified visual preview of the calculated arrangement. The preview is generated from the dimensions, margins, gaps, rows, columns, and orientation produced by the current calculation. It is intended as an explanatory representation of the estimate rather than a photograph, document scan, or capture of content from another webpage.

The preview does not require access to the user's camera, photos, unrelated browser tabs, or external design files for its standard operation. Its purpose is to make the mathematical packing result easier to interpret before the user decides whether to keep or export the calculated summary.

7. CSV export

The extension provides a user-initiated CSV export so the current packing calculation can be saved outside the popup. The generated file may contain the measurement inputs, calculated fit information, orientation comparison, waste estimate, or other summary values shown by the extension at the time the export is requested.

Exporting a CSV is an explicit user action. Once the file has been saved, its later storage, synchronization, backup, editing, or sharing is controlled by the user's device, browser, file manager, or third-party services selected by the user. Flintfold Packing Grid does not control an exported file after it has been created and handed to the browser's normal download workflow.

8. Browser permissions

Flintfold Packing Grid is intended to use only the Chrome capabilities necessary for its published calculator, interface, and export behavior. A permission included in a distributed version should have a direct relationship to a visible extension feature and should not be treated as authorization to collect unrelated information merely because the browser technically exposes additional capability.

The extension's stated purpose does not require continuous monitoring of browsing history, interception of communications, collection of credentials, or reading arbitrary website content. If a future version introduces a new permission or feature that materially changes how information is handled, the permission should remain limited to that feature and this Privacy Policy will be updated where the privacy impact changes.

9. Data sharing, sale, analytics, and advertising

Flintfold Packing Grid does not sell the measurements entered into its calculator or the packing results generated from them. Those values are not intended to be supplied to data brokers, advertising networks, or unrelated third parties for behavioral advertising, audience creation, cross-context profiling, or enrichment of marketing databases.

The extension's core packing calculation does not depend on third-party advertising technology. It is not designed to combine packing measurements with activity from unrelated websites in order to infer identity, interests, purchase intent, employment details, or other personal characteristics. Any future integration that materially changes this position would require corresponding disclosure in an updated policy.

10. Data retention and user control

Flintfold Packing Grid is intended to retain only the information needed to provide its immediate functionality or to preserve a setting when a released feature explicitly requires persistence. The product is not designed to maintain a remote archive of every packing calculation performed by a user or a longitudinal history of individual planning activity.

Temporary calculation state can be replaced simply by entering new values or closing the extension interface according to the behavior of the current build. CSV files remain wherever the user chooses to save them and can be renamed, moved, or deleted using normal operating-system tools. If a future release stores extension preferences locally, users can generally remove extension-local data by clearing extension data or uninstalling the extension.

11. Security and privacy-by-design

Flintfold Packing Grid reduces privacy exposure by keeping its functional scope narrow. A packing calculator normally needs dimensions and spacing values, not access to personal accounts, unrelated page content, contacts, or credentials. Limiting the categories of information required by the product is an important part of its privacy design because data that is never needed for the task does not need to be collected for the task.

No browser extension or computing environment can be guaranteed to be completely risk-free. Users should keep Chrome and the extension updated, restrict access to their device, and use appropriate care if the measurements or exported CSV files relate to confidential facilities, inventory, manufacturing, logistics, or other sensitive business planning. The extension should not be used as a repository for secrets, credentials, or unrelated personal records.

12. Children's privacy

Flintfold Packing Grid is a general-purpose measurement and planning utility and is not directed to children as a specific audience. Its normal workflow does not intentionally request a child's name, contact information, school information, precise location, photographs, or other personal profile details in order to calculate a packing arrangement.

Because the core tool is designed to work without user accounts or personal profiling, its ordinary operation does not depend on knowingly collecting personal information from children. If future features materially change that design, this policy will be reviewed and revised as appropriate before those practices are represented as part of the extension.

13. Changes to this policy

This Privacy Policy may be updated when Flintfold Packing Grid changes its calculation features, permissions, persistence behavior, CSV workflow, or other practices that affect how information is handled. Editorial changes may also be made to improve readability, correct terminology, or clarify an existing practice without introducing a new use of information.

When a material privacy-related change is made, the effective date shown at the top of this page will be updated. Users are encouraged to review the current policy when installing or updating a version that introduces new browser capabilities, new data flows, or new features involving storage or external services.

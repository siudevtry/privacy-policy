Privacy Policy for Lexivy

Last updated: August 22, 2026

This Privacy Policy describes how information is accessed, processed, and handled when you install or use the Lexivy browser extension.

Lexivy is a lightweight language reference extension that provides dictionary-style definitions, synonyms, and usage notes for words or phrases selected by the user.

Users can activate Lexivy through a right-click context menu. After the user deliberately requests the feature, Lexivy may access the selected word or phrase on the currently active webpage and display relevant language information in a compact popup without requiring the user to leave the page.

Lexivy is designed around user-initiated interaction. The extension does not need continuous access to every webpage simply to provide its core functionality.

Privacy Summary

Lexivy accesses selected text only when the user intentionally activates the extension. It is not designed to continuously monitor browsing activity or automatically inspect every webpage visited by the user.

The extension uses browser permissions such as contextMenus, activeTab, and scripting to provide its dictionary popup on demand.

1. Scope of This Privacy Policy

This Privacy Policy applies specifically to the Lexivy browser extension and the functionality provided directly through the extension.

It does not govern independent websites, search engines, browser vendors, external platforms, or other third-party services that users may access separately while browsing the internet.

2. Information Lexivy May Access

In order to provide its core functionality, Lexivy may temporarily access a word or phrase that the user has actively selected on the current webpage.

This access occurs in connection with a deliberate user action, such as selecting text and choosing the Lexivy command from the browser's right-click context menu.

Lexivy does not require unrestricted collection of webpage content in order to perform its intended function.

3. Selected Words and Phrases

When a user selects a word or phrase and activates Lexivy, the selected text may be processed for the purpose of generating relevant language information.

The resulting information may include:

  • Dictionary-style definitions;
  • Synonyms;
  • Alternative meanings;
  • Usage notes;
  • Word explanations;
  • Phrase explanations; and
  • Other language reference information related to the selection.

Selected text is accessed only in connection with the feature requested by the user and is not intended to be used for unrelated purposes such as advertising, behavioral profiling, or cross-site tracking.

4. Information We Do Not Require

Lexivy does not require users to provide ordinary personal information in order to access its core dictionary functionality.

The extension does not require information such as:

  • Full name;
  • Postal address;
  • Phone number;
  • Government identification number;
  • Payment card information;
  • Bank account information;
  • Medical information;
  • Biometric identifiers; or
  • Other unrelated sensitive personal information.

5. User Accounts

Lexivy does not require users to create a dedicated Lexivy account in order to use its standard dictionary popup functionality.

Users are not required to create a username, password, public profile, or personal account merely to look up selected words or phrases.

6. User-Initiated Access

Lexivy is designed so that its primary functionality begins only after a user performs an intentional action.

A typical interaction may involve:

  • Selecting a word or phrase on a webpage;
  • Opening the browser's right-click context menu;
  • Selecting the Lexivy command;
  • Allowing the extension to access the active tab for that action;
  • Processing the selected text; and
  • Displaying the requested dictionary information.

Lexivy is not designed to continuously scan text on every open webpage in the background.

7. Browser Permissions

Lexivy requests certain browser extension permissions that are necessary to provide its disclosed functionality.

The requested permissions are intended to be used only for purposes reasonably related to the features described in the extension's browser store listing.

contextMenus Permission

Lexivy uses the contextMenus permission to add a Lexivy option to the browser's right-click context menu.

This allows users to intentionally activate the dictionary popup after selecting a word or phrase.

The permission helps ensure that Lexivy operates only when the user chooses to invoke it from the context menu rather than automatically running on every page.

activeTab Permission

Lexivy uses the activeTab permission to obtain temporary access to the currently active browser tab after a qualifying user interaction.

This temporary access allows the extension to work with the text selected by the user and display definitions or related language information on that page.

The activeTab permission is used instead of requesting unnecessary permanent access to all websites whenever possible.

scripting Permission

Lexivy uses the scripting permission to inject the code required to display the dictionary popup or related interface in the currently active tab after the user requests the extension's functionality.

This permission allows Lexivy to present definitions, synonyms, and usage notes directly on the webpage without requiring users to navigate away from their current content.

Script injection is intended to occur only as necessary to perform the requested feature.

8. Purpose Limitation for Permissions

Browser permissions available to Lexivy are not intended to be used for unrelated surveillance, user profiling, advertising, or data brokerage.

Permissions are used only to support features that users reasonably expect from a dictionary and language reference extension.

Lexivy does not use these permissions for the purpose of secretly monitoring unrelated browsing behavior.

9. Webpage Content

Lexivy may interact with the current webpage when the user activates the extension.

This interaction is limited to what is technically necessary to identify the user's selected text and display the requested dictionary interface.

Lexivy is not intended to copy, archive, index, or analyze the complete content of every webpage a user visits.

10. Browsing History

Lexivy is not designed to create a history of websites visited by the user.

It does not use the user's browsing activity to build an advertising profile, behavioral profile, or cross-site identity.

Lexivy does not require a complete browsing history in order to provide definitions, synonyms, or usage notes for user-selected text.

11. Search History

Lexivy is not designed to collect a user's general web search history.

Words or phrases intentionally selected for lookup are used only in connection with providing the requested language reference functionality.

Such selections are not intended to be used to infer unrelated interests, purchasing behavior, political opinions, health information, or other personal characteristics.

12. Personal Information

Lexivy does not require personally identifiable information to provide its primary features.

If a user happens to select text containing personal information on a webpage, Lexivy may technically process that selected text because the user explicitly requested a lookup for it.

Users should avoid intentionally submitting passwords, authentication credentials, financial information, government identifiers, or other highly sensitive information for dictionary lookup.

13. Sensitive Information

  • Banking credentials;

14. Financial Information

The extension is not designed to collect bank account numbers, credit card numbers, payment credentials, transaction authentication information, or similar financial data.

15. Location Information

The extension is not intended to track the physical location or movement of users.

16. Advertising

Lexivy does not use selected words, phrases, webpage activity, or browser permissions to create targeted advertising profiles.

User-selected text is not intended to be processed for behavioral advertising, remarketing, or cross-site advertising purposes.

17. Sale of User Data

Lexivy does not sell user-selected text or personal information to data brokers, advertisers, marketing organizations, or other third parties.

18. User Profiling

Lexivy does not use selected words or browsing activity to build behavioral profiles of individual users.

Lexivy does not use selected text or browser activity to create persistent cross-site tracking profiles.

20. Cookies

The extension is not designed to place tracking cookies on unrelated websites for behavioral advertising or cross-site monitoring.

Websites independently visited by users may use their own cookies and tracking technologies. Such technologies are controlled by those websites and are subject to their respective privacy policies.

21. Browser Storage

Lexivy may use browser-provided storage mechanisms when necessary to remember functional preferences, configuration values, or extension settings.

Browser storage used for this purpose is intended to improve usability and support extension functionality.

22. Dictionary Requests

When Lexivy is activated, the selected word or phrase may need to be processed in order to obtain or generate dictionary information.

Any processing of selected text should be limited to what is reasonably necessary to provide the requested definition, synonym, usage note, or other language reference result.

Lexivy does not intentionally use dictionary requests for unrelated advertising or tracking purposes.

23. Data Minimization

Lexivy follows the principle of data minimization by limiting access to information reasonably necessary for its disclosed functionality.

For example, Lexivy uses temporary access to the active tab after user interaction rather than relying on unnecessary continuous access to all webpages whenever possible.

The extension also operates around specifically selected words or phrases rather than requiring the wholesale collection of browsing content.

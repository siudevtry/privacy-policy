Privacy summary Caskline Batch Splitter is a calculation and planning tool. Values entered for batch planning are used to produce the requested plan and are not intended to be used for behavioral tracking, advertising profiles, or unrelated browsing analysis.

1. Overview

Caskline Batch Splitter helps users divide a total quantity into practical batches, compare balanced and capacity-based allocation approaches, estimate timing information, and review the resulting schedule directly in the browser. This policy applies to the Caskline Batch Splitter Chrome extension and describes the privacy treatment of information handled through those functions.

The extension is designed around data minimization. It needs planning values only to perform the calculation the user requests. Its core purpose does not require building a profile of the user, identifying the user across websites, reading unrelated browsing content, or collecting personal information for secondary commercial use.

2. Extension purpose

The sole product purpose of Caskline Batch Splitter is to provide an in-browser batch-planning workspace. Users can enter a total amount, target batch size, setup time, maximum batch size, processing rate, and related planning preferences; the extension then calculates an organized schedule so different splitting strategies can be compared quickly.

The extension may also present summary values such as batch count, largest and smallest batch, estimated processing time, and a row-by-row schedule. These outputs are derived from the values supplied by the user for the current planning task. They are not intended to represent personal attributes, browsing behavior, or analytics about the user.

3. Planning inputs and calculated results

Information typed into the extension can include numerical planning values such as total units, target batch size, setup minutes, maximum batch size, processing rate, and optional plan settings such as whether a balanced plan is preferred or whether batch times should be rounded. These values are operational inputs, not account information.

Caskline Batch Splitter uses those inputs to calculate batch sizes, timing estimates, totals, and schedule rows. The results exist to help the user evaluate a workload or allocation scenario. The extension does not need names, email addresses, passwords, payment information, precise location, contacts, or the content of unrelated web pages to perform these calculations.

4. Information we collect

Caskline Batch Splitter is not designed as a data-collection service. It does not require a user account or sign-in to perform its core batch calculations, and the planning interface is intended to operate without asking the user to provide personal profile information.

The extension does not use the planning values entered into its calculator for targeted advertising, cross-site tracking, sale of user data, or creation of marketing profiles. It also does not need to inspect browsing history, search history, private messages, form entries on unrelated websites, or page content outside the extension in order to generate a batch plan.

A quantity or operational value can still be sensitive in a particular business context. Users should therefore enter only the information necessary for the calculation they want to perform.

5. Local processing

Batch calculations are designed to be performed within the extension environment. When a user changes an input or builds a plan, the extension applies its calculation logic to those values and displays the result in the interface. This local-processing model keeps the tool focused on the immediate planning task rather than on transmitting calculation inputs for remote profiling or analysis.

Caskline Batch Splitter does not need a remote account database to determine batch sizes or schedule timing. The extension's planning logic is intended to work from the values available in the active extension session. Any temporary values held by the page while it is open are used to keep the interface responsive and to produce the requested output.

6. CSV export

The extension can generate a CSV representation of the calculated schedule. When the user chooses to download a CSV, the file is created from the plan currently shown in the extension so the user can keep, review, or process the schedule outside the browser.

Export is initiated by the user. After a CSV file has been saved to the user's device, that file is under the user's control and is subject to the storage, backup, synchronization, sharing, and security settings of the device or services the user chooses to use. Caskline Batch Splitter does not control how an exported file is handled after the download is completed.

7. Browser permissions

Caskline Batch Splitter is intended to request only the browser capabilities required for its published functionality. Any permission included in a distributed build must be used to support the extension's batch-planning, interface, preference, or export behavior and not to obtain unrelated access to the user's browsing activity.

In particular, the extension's purpose does not require reading the content of arbitrary websites, monitoring the user's browsing history, collecting credentials, or intercepting communications. If a future version requires an additional Chrome permission, that permission will be limited to a feature with a clear product purpose and this policy will be updated when the privacy impact materially changes.

8. Data sharing, sale, analytics, and advertising

Caskline Batch Splitter does not sell user information. Planning values and calculated schedules are not intended to be supplied to data brokers, advertising networks, or third parties for behavioral advertising, audience segmentation, or cross-context tracking.

The extension's core batch-planning functions do not depend on third-party advertising technology. It is not designed to combine extension inputs with data from unrelated websites in order to infer interests, purchasing behavior, identity, or other personal characteristics.

9. Data retention and user control

The extension is intended to retain only information needed to provide its immediate functionality or to preserve settings when a feature explicitly does so. It is not designed to maintain a remote historical archive of every batch plan a user creates. Closing or resetting the extension removes transient session state according to the implementation of the current version.

CSV files are retained only wherever the user chooses to save them. Users can delete exported files using the normal file-management tools on their device. If browser-stored preferences are present in a release, users can generally remove that extension-local data by clearing extension data or uninstalling the extension.

10. Security and privacy-by-design

Caskline Batch Splitter reduces privacy exposure primarily by limiting the amount and type of information needed for the service. A calculator that can operate from user-entered planning values does not need broad access to personal accounts or unrelated browsing data, so the product is designed to keep those categories outside its normal operating scope.

No software environment can be described as absolutely risk-free. Users should keep Chrome and the extension up to date, protect access to their device, and use appropriate care when exporting operational information that may be confidential in their own organization. The extension should not be treated as a secure vault for secrets or credentials.

11. Children's privacy

Caskline Batch Splitter is a general-purpose productivity and planning utility and is not directed toward children as an audience. The extension does not intentionally request information such as a child's name, school, contact details, precise location, or other profile information as part of its batch-planning workflow.

Because the tool is designed to function without user accounts or personal profiling, its ordinary operation does not depend on knowingly collecting personal information from children. If the extension's functionality changes in a way that materially affects this position, this policy will be revised accordingly.

12. Changes to this policy

This Privacy Policy may be updated when Caskline Batch Splitter changes its functionality, permissions, storage behavior, export workflow, or other practices that affect privacy. Minor wording or formatting changes may also be made to improve clarity without changing the underlying privacy practices.

When a material change is made, the effective date shown at the top of this page will be updated. Users are encouraged to review the current policy when installing a new version if that release introduces features that handle information in a different way.
